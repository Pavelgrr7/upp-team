# Гайд по работе с Git в VS Code

Все действия выполняются во вкладке **Source Control (Управление версиями)** — иконка с тремя точками и ветками на панели слева (или `Ctrl + Shift + G`).

---

## 1. Начало работы
Перед тем как начать писать код в любой день:
1. Откройте проект в VS Code.
2. Внизу слева или во вкладке Git нажмите на **значок круговых стрелочек (Синхронизация/Pull)**.
3. Это скачает последние изменения, которые сделали другие участники.

---

## 2. Как сохранить и отправить свою работу (Commit & Push)
Когда вы написали или изменили свой файл:
1. Перейдите во вкладку **Source Control** слева.
2. В поле **Message (Сообщение)** напишите кратко, что сделали (например: *«добавил тестовую кнопку»* или *«собрал список групп»*).
3. Нажмите синюю кнопку **Commit (Зафиксировать)**.
4. Нажмите кнопку **Sync Changes (Синхронизировать изменения)** или стрелочку вверх.
5. Ваш код отправлен на GitHub!

---

## 3. Что делать, если Git ругается или что-то сломалось?
* Скопируйте ваш рабочий файл в другую папку/на рабочий стол, напишите мне в лс и прикрепите скриншот ошибки. 
* Мы все поправим и разберёмся, ваш код никуда не пропадет !
